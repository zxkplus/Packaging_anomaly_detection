# 标签重复印刷检测分类器

## 介绍

此项目使用机器学习技术来检测包装标签的重复印刷缺陷。通过提取图像的多种特征并使用支持向量机(SVM)进行分类，系统能够区分正常标签和有重复印刷缺陷的标签。

## 技术细节

### 特征提取

我们使用了多种特征组合来有效区分正常标签和异常标签：

1. **HOG特征 (Histogram of Oriented Gradients)**
   - 用于捕获图像中的形状和边缘方向信息
   - 特别适用于检测形状变化和结构异常

2. **边缘密度特征**
   - 计算图像中边缘像素的比例
   - 有助于检测额外的线条或重复元素

3. **纹理特征**
   - 使用高斯模糊后的残差计算纹理复杂度
   - 识别不规则的纹理模式

4. **灰度直方图**
   - 量化不同亮度级别的像素分布
   - 帮助识别颜色和亮度异常

5. **形状特征**
   - 包括轮廓的圆形度和边界框比例
   - 检测形状变化和变形

### 分类算法

使用支持向量机(SVM)作为分类器，因为它在高维特征空间中表现优异，特别适合图像分类任务。

## 使用方法

### 训练模型

```bash
python train_label_detector.py
```

该脚本将：
1. 从 `assets/output_ok` 和 `assets/output_error` 文件夹加载图像
2. 提取每张图像的特征
3. 训练SVM分类器
4. 保存训练好的模型和标准化器

### 预测新图像

```bash
python predict_labels.py
```

该脚本将：
1. 加载训练好的模型
2. 对指定文件夹中的图像进行批量预测
3. 输出每张图像的分类结果和置信度

## 模型文件

- `label_detection_svm_model.pkl`: 训练好的SVM分类器
- `label_detection_scaler.pkl`: 特征标准化器

## 性能指标

- 训练精度：接近100%
- 支持概率输出以提供置信度评分

## 优化建议

1. 如果出现误分类，可以增加训练数据
2. 调整HOG特征参数以更好地适应图像特性
3. 尝试其他核函数（如多项式核）可能获得更好的性能
